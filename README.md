## CI/CD Pipeline

Deployments are fully automated using **GitHub Actions**.

Every push to the `main` branch:

1. Triggers the workflow automatically
2. Builds the Blazor WebAssembly project
3. Publishes the compiled output
4. Deploys to GitHub Pages with zero manual steps

This means the live site is always in sync with the latest version of the codebase.

```yaml
# .github/workflows/deploy.yml
name: Deploy to GitHub Pages
on:
  push:
    branches:
      - main
```
